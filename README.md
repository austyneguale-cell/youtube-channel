# YouTube Channel Management System

A comprehensive automation system for managing the Eshibaba YouTube channel, including:
- Video production and editing workflows
- Content planning and tracking
- Automated publishing pipeline
- Quality control and approval gates

## Project Structure
- `/content/` - Raw content and assets
- `/production/` - Production files and scripts
- `/brand/` - Brand assets and guidelines
- `/docs/` - Documentation
- `/channel/` - Channel management files
